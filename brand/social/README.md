# Riocut social app icons

Two styles of the same logo. Upload whichever a console accepts.

- `riocut-icon-*.png` — rounded teal square, **transparent** corners (RGBA).
- `riocut-appicon-*.png` — full-bleed teal square, **opaque** (RGB). Use where the
  platform applies its own rounded mask or rejects transparency.

| Platform / place | File |
|---|---|
| Google OAuth consent screen (needs 120×120) | `riocut-icon-120.png` |
| Meta app icon (Facebook/Instagram, 1024×1024) | `riocut-appicon-1024.png` |
| TikTok app icon (1024×1024) | `riocut-appicon-1024.png` |
| X / Twitter app icon (400×400) | `riocut-appicon-400.png` |
| LinkedIn app logo (300×300) | `riocut-appicon-300.png` |
| General / stores / 512 | `riocut-appicon-512.png` or `riocut-icon-512.png` |

Regenerate from `apps/web/src/app/icon.svg` if the mark changes.
